REPLIT BUILD PROMPT — P4: UI Design System & Layout Shell
Context: Phase 3 is complete. We have a dark-themed login page and 8 role-based dashboards at their respective routes. Phase 4 establishes the full UI design system as reusable components and builds the persistent layout shell that all dashboards will live inside going forward.

OBJECTIVE
Build the global layout shell and a reusable component library that enforces the Axel Workforce OS design system. Every dashboard route built in P3 should be refactored to use this shell.

DESIGN SYSTEM RULES (NON-NEGOTIABLE)

Background: #060608 — base for all screens
Accent: #E91E8C (solid pink) — the ONLY accent color. No other accent colors.
NO gradients on any UI element — solid colors only
Glassmorphism panels: background: rgba(255,255,255,0.05), backdrop-filter: blur(12px), border: 1px solid rgba(255,255,255,0.08), border-radius: 12px
Typography: White primary text, rgba(255,255,255,0.5) for secondary/muted text
Mode: Dark default. Light mode toggle in top-right corner of the shell header.


LAYOUT SHELL — STRUCTURE
Build a <AppShell> React component that wraps all authenticated views. It must include:
1. Collapsible Left Navigation

Collapsed state: icons only. Expanded state: icons + labels.
Toggle button (hamburger/arrow) at the top of the nav.
Use Lucide React icons throughout — no other icon library.
Nav items vary by role. Accept a navItems prop (array of { label, icon, path }).
Active route highlighted with #E91E8C accent — left border or background tint, not a gradient.
Glassmorphism nav panel: same frosted glass spec above.

2. Top Header Bar

Left: Axel Workforce OS wordmark / logo area
Right: Light/dark mode toggle + user avatar with dropdown (Profile, Settings, Logout)
Glassmorphism surface

3. Main Content Area

Fills remaining space to the right of the nav
Overflow scroll on content, not on the shell itself
Padding: 24px

Phase 6: Pipeline Module — 10-Stage Kanban & Deal Cards
Context: Phases 1–5 are complete. The app has AppShell, role-based dashboards, a full component library in /components/ui/, and a working Marketplace module. All UI must use AppShell as wrapper and pull from /components/ui/ for all components.

OBJECTIVE
Build the Pipeline module — a 10-stage Kanban board where internal Axel staff manage deals from New Lead through to Client. Each deal is represented by a deal card that can be opened as a glassmorphism overlay modal.

ROUTE
/pipeline
Accessible to: Admin, CSA, Agent roles. Gate all others out.

PAGE LAYOUT
Inside AppShell:

SectionHeader: title "Pipeline", subtitle showing total deal count and total WC premium in view (e.g. "24 deals · $1,240,000 WC Premium")
Below header: horizontal scrolling Kanban board — 10 columns, one per stage
Top right: PinkButton "New Deal" — opens the New Deal form (see below)


THE 10 PIPELINE STAGES
Stage #Name1New Lead2Qualified3Needs Analysis4Proposal Sent5Negotiation6Decision Pending7Committed8Documentation9Bound10Client
Each column:

Column header: stage number + stage name, muted white text
Stage card count badge (Badge component) next to the header
GlassCard column container, vertically scrollable if cards overflow
Column width: fixed 280px, horizontal scroll on the board container


DEAL CARDS (in-column display)
Each deal card is a GlassCard inside its column. Display:

Business name (bold, white)
Vertical (muted text with a small Lucide icon)
Quote type badge: "WC" or "PEO" — use Badge component, solid colors (WC = blue #1E6BE9, PEO = pink #E91E8C)
WC Premium line: e.g. $42,000 WC Premium
WFS PEPM line (PEO deals only): e.g. $18 PEPM — omit entirely for WC-only deals
Assigned team member avatars (up to 3, stacked with overlap, hover tooltip shows name)
Click anywhere on the card → opens Deal Card Modal (built in P7 — for now open a placeholder modal)

Hover state: card border brightens to rgba(233,30,140,0.3)

NEW DEAL FORM
PinkButton "New Deal" opens a Modal (from /components/ui/) containing:

Business Name (text input)
Vertical (dropdown — same 8 verticals from Marketplace)
Quote Type (toggle or select: WC Only / PEO+WC)
State (50-state dropdown)
Estimated Annual Payroll (currency input)
Number of Employees (number input)
Assigned To (dropdown — placeholder user list for now)
PinkButton "Create Deal" — saves to Supabase deals table, places card in Stage 1 (New Lead), closes modal
GhostButton "Cancel"

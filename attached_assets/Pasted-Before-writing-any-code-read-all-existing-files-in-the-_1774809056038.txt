PHASE 3 — PARTY ENVIRONMENTS + DASHBOARDS

Build the eight distinct party environment dashboards. Each party type 
has its own authenticated view with role-specific navigation and a 
dashboard home screen showing relevant data.

PARTY TYPES TO BUILD:
1. Admin (internal Axel staff — full platform access)
2. Underwriter (internal — deal review and approval)
3. CSA / Account Manager (internal — client servicing)
4. Agent / Broker (external — submits business)
5. Employer / Client (external — views their account)
6. Carrier (external — views bound business)
7. PEO Partner (external — views PEO accounts)
8. Vendor (external — views assigned tasks)

---

ROUTING STRUCTURE:

/dashboard/admin
/dashboard/underwriter
/dashboard/csa
/dashboard/agent
/dashboard/employer
/dashboard/carrier
/dashboard/peo
/dashboard/vendor

Each route must be protected by:
1. Authentication check (redirect to /login if no session)
2. Role check (redirect to /unauthorized if wrong role)
3. RLS on all Supabase queries (data scoped to party's org_id)

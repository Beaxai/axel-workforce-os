R.3: Rating Engine UI Integration
Context: R.1 and R.2 are complete. The rate table has 24,824 records in Supabase and the rating engine backend is fully tested with both /api/rate/wc and /api/rate/wfs endpoints live. R.3 wires the rating engine into the frontend — replacing the placeholder quote form built in P5 with a fully functional quote, proposal, and deal-saving flow.

OBJECTIVE
Wire the rating engine into the UI. A user selects a vertical and quote type in the Marketplace, fills in the quote form, hits Calculate, sees a full proposal breakdown, and can save it as a deal in the Pipeline.

PART 1 — UPGRADE THE QUOTE FORM (/marketplace/quote/new)
The placeholder form from P5 already has these fields: Business Name, State, Annual Payroll, Number of Employees, Primary Class Code, EMod, Schedule Rating. Keep all of these. Make the following changes:
Add quote type context display:

At the top of the form, show a read-only context bar (GlassCard, muted): Vertical name + Quote Type (WC Only or PEO+WC) — passed in from the Marketplace card click

EMod and Schedule Rating defaults:

Both default to 1.0 — already done in P5, confirm this is still in place

"Calculate Quote" button behavior (replace the console.log placeholder):

Validate all fields client-side before calling the API — show inline field errors for any missing or invalid values
Call POST /api/rate/wc with form values
If quote type is PEO+WC, also call POST /api/rate/wfs simultaneously
Show a loading state on the button while API calls are in flight ("Calculating..." with a Lucide Loader spinning icon)
On success: scroll down to the Proposal Panel (built below) and populate it with results
On error: show an error message in a red-bordered GlassCard below the form: "Rating error: [error message from API]"

Below the proposal numbers:

Two buttons side by side:

PinkButton "Save as Deal" — see Part 3
GhostButton "Recalculate" — scrolls back up to form, keeps values populated




PART 3 — SAVE AS DEAL
PinkButton "Save as Deal" opens a Modal with:

Business Name (pre-filled from quote form)
Vertical (pre-filled)
Quote Type (pre-filled, read-only)
State (pre-filled)
Assigned To (team member dropdown)
PinkButton "Create Deal"

On "Create Deal":

Create a record in the deals table (Stage 1 — New Lead)
Create a record in the quotes table with full wc_rating_breakdown and wfs_rating_breakdown JSON, linked to the new deal via deal_id
Generate the listener email address and save to deal_email_addresses table
Close the modal
Show a success toast notification: "Deal created — [Business Name] added to Pipeline" with a Lucide CheckCircle icon in pink
GhostButton "View in Pipeline" in the toast → navigates to /pipeline


PART 4 — DEAL CARD MODAL RATING TAB
Add a "Quote" tab to the Deal Card Modal (built in P7). This tab shows the saved rating breakdown for that deal.
Tab content:

If no quote exists yet: "No quote on file. Generate a quote from the Marketplace." with a GhostButton "Go to Marketplace"
If a quote exists: render the full Proposal Panel (reuse the component from Part 2 — make it a shared <ProposalPanel> component) in read-only mode
Show rated_at timestamp: "Quoted on [date]"

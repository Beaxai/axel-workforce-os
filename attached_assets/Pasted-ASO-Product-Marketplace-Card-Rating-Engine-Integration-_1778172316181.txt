ASO Product: Marketplace Card + Rating Engine Integration
CONTEXT
We are adding a new product type to Axel Workforce OS: ASO (Administrative Services Organization). ASO is distinct from PEO in that there is no co-employment relationship — the client remains the sole employer of record. ASO sells software + administrative support (payroll, HR, benefits, compliance). The client keeps their own WC policy — Axel collects WC exposure data for underwriting reference but does not quote or price WC through the ASO path.
Key distinctions:

PEO = co-employment + bundled WC + workforce infrastructure
ASO = admin support only, client keeps full employer responsibility and their own WC policy
ASO quotes = PEPM only — no WC premium line item
ASO rating basis = $50.00 PEPM flat rate
WC exposure data is collected on the ASO quote form for underwriting reference only

PART 2 — RATING ENGINE: ASO QUOTE FLOW
ASO pricing model: flat $50.00 PEPM — no WC component priced or displayed.
Quote Form Fields
Section 1 — Administrative Info:

Company name
State (dropdown)
Effective date
Number of employees (headcount)
Total annual payroll (total_payroll) — collected for WC reference, not used in PEPM calculation

Section 2 — Workers' Compensation Info:
Label this section: "Workers' Compensation Info (for underwriting reference)"
Helper note directly under section header: "Your WC policy remains in your company's name. This information is collected for our underwriting team's reference only."
Fields:

Class code(s) — use the same class code selector used in the WC/PEO flows
Payroll per class code (if split payroll applies)
Current WC carrier (text field)
Current WC policy expiration date (date field)
Experience modification factor / EMod (numeric field, default value 1.0)
Current WC annual premium (text field — what they are paying today)

None of the WC fields feed the PEPM calculation. They are collected for storage only.

ASO PEPM Formula
pepm = 50.00  (flat rate — no payroll-based calculation)
monthly_aso_fee = pepm × headcount
annual_aso_fee = monthly_aso_fee × 12

The $50.00 PEPM rate should be stored as a named constant: ASO_BASE_PEPM_RATE = 50.00
Do not hardcode 50 inline — reference the constant so the rate can be updated in one place
Display as a single line item: Administrative Services $50.00 PEPM
No WC premium line under any circumstance
No minimum premium logic
No EMod, schedule rating, or payroll multiplier applied to the PEPM


Quote Results Display
Follow the same results card pattern used for PEO quotes. Show:

Administrative Services: $50.00 PEPM
Monthly Total: $X,XXX.00 (headcount × $50.00)
Annual Total: $XX,XXX.00 (monthly × 12)

No WC line item rendered.

Quote Record
Insert into the existing quotes table:

product_type = 'ASO'
wc_premium = null
monthly_fee = monthly_aso_fee
pepm = 50.00
rating_breakdown = full JSON (see below)

  "annual_aso_fee": <number>,
  "total_payroll": <number>,
  "effective_date": "<date>",
  "state": "<string>",
  "wc_reference": {
    "class_codes": [...],
    "current_carrier": "<string>",

  }
}

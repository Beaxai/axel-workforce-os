RATING ENGINE — SERVER SIDE
Create the rating engine at /utils/ratingEngine.js.
It must export two functions: calculateWCPremium and calculateWFSPEPM.

FUNCTION 1 — calculateWCPremium
javascriptasync function calculateWCPremium({ state, classCode, annualPayroll, eMod, scheduleRating, isPEO })
```

**Logic:**

1. Look up base rate using `getWCRate(state, classCode)` — if no rate found, throw an error: `"No rate found for state [state], class code [classCode]"`
2. Calculate gross premium:
```
   grossPremium = (annualPayroll / 100) * baseRate * eMod * scheduleRating
```
3. Apply minimum premium: if `grossPremium < 500`, set `grossPremium = 500`
4. Apply PEO discount if `isPEO === true`:
```
   peoDiscount = grossPremium * 0.10
   finalPremium = grossPremium - peoDiscount
If isPEO === false: peoDiscount = 0, finalPremium = grossPremium
5. Build and return rating_breakdown object:
javascript{
  inputs: {
    state,
    classCode,
    annualPayroll,
    eMod,
    scheduleRating,
    isPEO
  },
  rateData: {
    baseRate,
    effectiveDate,   // from wc_rates row
    description      // class code description from wc_rates row
  },
  calculation: {
    payrollPer100: annualPayroll / 100,
    grossPremium,
    minimumPremiumApplied: grossPremium === 500 && (annualPayroll / 100) * baseRate * eMod * scheduleRating < 500,
    peoDiscountApplied: isPEO,
    peoDiscountAmount: peoDiscount,
    finalPremium
  },
  result: {
    wcPremium: finalPremium
  },
  calculatedAt: new Date().toISOString()
}

FUNCTION 2 — calculateWFSPEPM
javascriptfunction calculateWFSPEPM({ annualPayroll, headcount })
```

```
monthlyWFSFee = (annualPayroll * 0.02) / 12

Return:

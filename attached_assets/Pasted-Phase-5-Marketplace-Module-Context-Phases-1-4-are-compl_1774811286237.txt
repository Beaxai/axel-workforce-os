Phase 5: Marketplace Module
Context: Phases 1–4 are complete. The app has a working auth system, 8 role-based dashboards, and a full UI design system with AppShell, glassmorphism components, and a collapsible left nav. All subsequent phases must use AppShell as the wrapper and pull from /components/ui/ for all UI elements.

OBJECTIVE
Build the Marketplace module — a vertical-based product marketplace where internal Axel staff can browse industry verticals and initiate either a WC-only or PEO/WC dual quote path.

ROUTE
/marketplace
Accessible to: Admin, CSA roles only (gate all other roles out).

PAGE LAYOUT
The Marketplace lives inside AppShell. Structure:

SectionHeader at top: title "Marketplace", subtitle "Select a vertical to begin a quote"
Below header: vertical card grid (responsive, 3 columns on desktop, 2 on tablet, 1 on mobile)
Each card is a GlassCard representing one industry vertical


VERTICAL CARDS
Each vertical card displays:

Vertical icon (Lucide icon — pick the most appropriate per vertical)
Vertical name (bold, white)
Short descriptor line (muted text, rgba(255,255,255,0.5))
Two action buttons side by side:

"WC Quote" — PinkButton
"PEO Quote" — GhostButton


Hover state: card border brightens to rgba(233,30,140,0.3)

Starting verticals to build (expandable later):

QUOTE PATH ROUTING
When a user clicks either button on a vertical card:

Store the selected vertical and quote type (WC or PEO) in app state (React context or local state — do not persist to DB yet, that happens in the rating engine phases)
Route to a quote initiation screen at /marketplace/quote/new
Pass vertical + quote type as route state or context

Quote initiation screen (/marketplace/quote/new):
This is a placeholder screen for now — full rating engine wires in during R.1–R.3. Build the screen with:

SectionHeader showing: "New [WC / PEO] Quote — [Vertical Name]"
A GlassCard containing a simple form with these fields:

Business Name (text input)
State (dropdown — all 50 US states)
Estimated Annual Payroll (number input, formatted as currency)
Number of Employees (number input)
Primary Class Code (text input — freeform for now)
EMod (number input, default value: 1.0)
Schedule Rating (number input, default value: 1.0)


PinkButton: "Calculate Quote" — disabled for now, logs form state to console
GhostButton: "Back to Marketplace"

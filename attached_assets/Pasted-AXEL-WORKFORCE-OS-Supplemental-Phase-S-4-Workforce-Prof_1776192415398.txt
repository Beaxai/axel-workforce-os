AXEL WORKFORCE OS — Supplemental Phase S.4: Workforce Profile Widget Integration

CONTEXT
All prior phases (P1–P10, R.1–R.3, S.1–S.5) are complete. This phase integrates the Workforce Profile Widget into the existing quote flow. The widget replaces the current single-class-code input on the quote form with a multi-location, multi-class-code workforce profile screen that feeds structured payroll data into the rating engine.

OBJECTIVE
Insert the Workforce Profile Widget as a dedicated step in the quote flow between the business information screen and the premium calculation screen. The widget collects: locations, class codes per location, FT/PT employee counts, and annual payroll per code. On "Continue to rating" it passes a structured payload to the existing rating engine.

PART 5 — ADD THE BACKEND AI ROUTE
Add to the Express backend at server/routes/ai.ts (or the existing routes index):
tsimport Anthropic from '@anthropic-ai/sdk';

router.post('/api/ai/classify', async (req, res) => {
  const { code, name, phraseology, state, question, history } = req.body;
  
  const client = new Anthropic();
  
  const system = `You are a senior WC underwriting engineer and classification expert. 
Code: ${code} — ${name}. 
Phraseology: ${phraseology}. 
State: ${state || 'not specified'}. 
Answer in under 140 words. Plain text only.`;

  const messages = [
    ...(history || []).slice(-6).map((m: any) => ({ role: m.role, content: m.content })),
    { role: 'user' as const, content: question },
  ];

  const response = await client.messages.create({
    model: 'claude-sonnet-4-20250514',
    max_tokens: 1000,
    system,
    messages,
  });

  res.json({ answer: response.content[0].type === 'text' ? response.content[0].text : 'Unable to answer.' });
});
ANTHROPIC_API_KEY is already set in Railway environment variables from prior phases.

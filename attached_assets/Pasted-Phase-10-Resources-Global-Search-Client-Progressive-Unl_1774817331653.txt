PART B — GLOBAL SEARCH
Global search is accessible from every screen via a search icon (Lucide Search) in the AppShell header bar, right side, next to the avatar.
Behavior:

Clicking the search icon opens a full-width search overlay (glassmorphism, appears over current screen)
User types a query — results appear in real time (debounced, 300ms)
Search spans: Deals (by business name), Accounts (by business name), Partners/Agents (by name), Resources (by title)
Results grouped by type with section headers: "Deals", "Accounts", "Partners", "Resources"
Each result shows: name/title, type badge, relevant secondary info (e.g. stage for deals, status for accounts)
Clicking a Deal result → calls openDealCard(dealId) (wired in P7)
Clicking an Account result → navigates to /accounts/[id]
Clicking a Partner result → navigates to appropriate detail page
Clicking a Resource result → opens/downloads the resource
ESC key closes the overlay
Empty state: "No results for '[query]'" with a muted message

Implementation:

Query Supabase directly from the frontend using ilike pattern matching on relevant text columns
No external search service needed at this stage
Wire the search icon into AppShell header now — it should be visible on all authenticated screens

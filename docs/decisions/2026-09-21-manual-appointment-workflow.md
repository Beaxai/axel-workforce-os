# Producer appointments — manual workflow for now

**Date:** September 21, 2026

**Status:** Decided; revisitable

**Source:** User instruction: “Make everything manual for now. Mark it in
decisions. We may want to automate parts of it later.”

## Decision

Use a staff-managed manual process for the entire producer appointment workflow
for now, not merely the final approval decision.

Staff handle intake review, agency/user matching and duplicate resolution,
document and signing coordination, scheduling and booking confirmation,
application updates, approval or decline, record creation/linking,
countersignature follow-up, activation, and credential handoff.
Communications and reminders are staff-initiated.

## Explanation

Keep staff in control of each step while the process is established. Automatic
matching, provisioning, workflow advancement, activation, and other appointment
automation are deferred. Individual steps may be automated later following a
separate decision about scope and safeguards.

Manual handling does not waive permissions, document privacy, required signatures,
or activation/credential prerequisites. Actual actions and evidence are still
required; do not simulate provider completion or bypass safeguards.

## Effect on existing plans and implementation

This supersedes earlier appointment automation plans as the current operating
direction. Those plans remain future backlog, not the current build mandate.
Preserve working tools and links for staff use.

This entry records the decision only. It does not claim that manual controls are
implemented or that existing background workers, integrations, or subscriptions
have been disabled. Any runtime changes must be scoped separately.
